# Study Library

Study Library — вымышленный учебный проект каталога книг.

## Назначение

Планируется хранить название книги, автора и отметку о прочтении.
Каталог предполагается сохранять в SQLite и дополнять поиском по автору.

## Состояние

В папке есть только это описание. Исходников и работающего приложения нет.
Способ запуска и тесты не определены. Заявленные возможности являются планом,
а не проверенной реализацией. Файл используется для проверки цепочки ассистента.
