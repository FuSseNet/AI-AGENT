# Study Planner

Study Planner — учебный проект персонального планировщика домашних заданий.
Он помогает студенту хранить список заданий, сроки сдачи и текущий статус работы.

## Возможности

- Добавление задания с названием, предметом и сроком сдачи.
- Просмотр списка предстоящих заданий.
- Изменение статуса: запланировано, в работе, завершено.

## Хранение данных

Задания предполагается хранить в локальном JSON-файле. Учётные записи,
синхронизация между устройствами и отправка уведомлений пока не реализованы.

## Состояние проекта

Это демонстрационное описание для проверки ассистента. Рабочего приложения
планировщика в этой папке пока нет. Ассистент не должен утверждать, что оно готово.
