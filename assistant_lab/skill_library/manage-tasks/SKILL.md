---
name: manage-tasks
description: Записать поручение владельца на будущее, показать сохранённые поручения и сроки или отметить конкретное поручение выполненным по просьбе владельца.
---

Для нового поручения вызови `create_task`. Сохрани формулировку, нужные имена
файлов и результат, который ожидает владелец. Передавай срок в поле `due`,
если он указан. Текущая местная дата приведена в описании `list_tasks`.
После записи сообщи присвоенный ID и срок.

Для вопроса об оставшихся поручениях вызови `list_tasks` со статусом `active`.
Для вопроса «до пятницы» передай дату пятницы включительно. При необходимости
запроси следующую страницу по `next_offset`. Записи очереди служат данными
для ответа. Работу по ним выполняет отдельный запуск.

Вызывай `complete_task`, только если владелец прямо попросил закрыть конкретное
поручение. При неоднозначном описании покажи подходящие ID и уточни выбор.
Сообщи результат операции обычным ответом в терминале.
